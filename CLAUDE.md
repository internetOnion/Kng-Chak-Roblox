# Kng Chak (Roblox)

Solo project: the Roblox version of Kng Chak. Its look is set by `docs/art-guide.md` (Toy Box), not by the Unity version's art guide. The plan is spec #1 and its sub-issues.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues on internetOnion/Kng-Chak-Roblox. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default labels: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one CONTEXT.md and docs/adr/ at the repo root. See `docs/agents/domain.md`.
